# 🌐 Portfolio Website – Sunny Pandey

A clean, responsive **portfolio website** built using **HTML, CSS, and JavaScript** to showcase my skills, projects, and contact links.

---

## 🚀 Live Demo
👉 [View Portfolio](https://sunnypandey01.github.io/portfolio-website/)

---

## 🧰 Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript (ES6)** – Smooth scrolling and interactivity  
- **GitHub Pages** – Free hosting and deployment  

---

## 🧑‍💻 Features
- Responsive design (works on mobile & desktop)  
- Smooth scrolling navigation  
- Sections for About, Skills, Projects, and Contact  
- Direct links to LinkedIn, GitHub, and Email
